2. Langkah Menambahkan Akun Karyawan Baru (HC Hub)
1
Login sebagai Admin / Human Capital
Login ke https://erpyayasan.com menggunakan akun Super Admin atau akun Human Capital (tazkia.aulia).
2
Buka Menu HC Hub ➔ Data Karyawan
Klik menu 👥 HC Hub di sidebar kiri, lalu pilih tab sub-menu Data Karyawan. Anda akan melihat tabel master seluruh 36 staf yayasan.
3
Klik Tombol "+ Tambah Karyawan Baru"
Klik tombol hijau + Tambah Karyawan Baru di pojok kanan atas tabel untuk memunculkan formulir pendaftaran.
4
Lengkapi Formulir Identitas & Hak Akses
Isi data karyawan secara lengkap:
  • NIKA & NIK: Nomor Induk Karyawan Yayasan (contoh: K-2026-037) dan NIK KTP 16 digit.
  • Nama Lengkap & Jabatan: Nama resmi sesuai KTP dan pilih jabatan kerja.
  • Role Sistem: Pilih hak akses sesuai tabel di atas (contoh: SURVEYOR atau PERWAKILAN_YAYASAN).
  • Alamat Email Aktif & No. HP: Masukkan email asli karyawan untuk menerima notifikasi otomatis.
  • Username & Password Awal: Buat username unik (contoh: ahmad.fauzi) dan password awal (default: password123).
  • Hak Kuota Cuti: Tetapkan kuota cuti tahunan (default: 12 hari) dan cuti pribadi (default: 3 hari/Q).
5
Simpan & Sinkronisasi Otomatis ke Cloud Supabase
Klik tombol 💾 Simpan Data Karyawan. Sistem akan langsung mengunggah profil akun ke tabel users di database Supabase Cloud sehingga karyawan bisa langsung login seketika!
3. Panduan Mengubah Email & Reset Password Karyawan
Kebutuhan Langkah Solusi Dampak ke Sistem
Karyawan Lupa Password Buka Data Karyawan ➔ Klik tombol Edit ✏️ pada baris nama yang bersangkutan ➔ Ganti kolom password ke password123 ➔ Klik Simpan. Password baru langsung aktif seketika di cloud.
Perubahan Email Notifikasi Edit profil karyawan ➔ Perbarui kolom Email ke alamat Gmail/kantor yang baru ➔ Klik Simpan. Surat approval cuti & PR berikutnya otomatis terkirim ke email baru.
Karyawan Resign / Nonaktif Edit profil ➔ Ubah status karyawan menjadi Nonaktif / Resign dan masukkan tanggal pengunduran diri. Akun dinonaktifkan dari akses portal ERP.
🔒 Keamanan Data Karyawan: Data NIK, nomor rekening bank, dan nomor darurat keluarga tersimpan secara terenkripsi di PostgreSQL Supabase dan hanya dapat dilihat oleh pemegang otoritas HC dan Direksi Utama.
